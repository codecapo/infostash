# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space: GitHub, the
community chat, events and anywhere you represent the project.

## In short

- Be welcoming and patient, especially with newcomers.
- Disagree with ideas, not people.
- No harassment, insults or personal attacks.
- Assume good intent, and ask before assuming the worst.

## Reporting

Report unacceptable behavior privately to the project maintainer,
[@codecapo](https://github.com/codecapo), by email (the address on their
GitHub profile). Reports are handled confidentially. A dedicated
`conduct@` address will replace this once the project domain exists.
Maintainers who are part of a report step out of handling it.

Enforcement follows the Contributor Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, permanent ban.
